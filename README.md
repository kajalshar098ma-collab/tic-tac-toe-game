# Tic Tac Toe Game 🎮

A simple Tic Tac Toe game made using:

- HTML
- CSS
- JavaScript

In this game:
- User plays as **X**
- Computer plays as **O**
- The game shows whose turn it is
- Restart button is included

---

## 📁 Files

Project contains 3 files:

1. `index.html`
2. `style.css`
3. `script.js`

---

## 🚀 How to Run

1. Download or clone this project
2. Open the folder
3. Double click `index.html`

OR

Open with Live Server in VS Code.

---

## 🎯 Features

- Simple UI
- User vs Computer
- Turn indicator
- Win detection
- Draw detection
- Restart game button

---

## 🖥️ Technologies Used

- HTML
